# Rules — Hello SUNA

<!-- House rules for agents working in this project. Short, checkable, and enforced by review rather than by the tool. -->

- Never edit a referee's words. `rounds/*/reviewers/*.json` is immutable; the
  reply belongs in `round.json`'s `pointStates`.
- Never mark a point Done. Status is the author's judgement, not the agent's.
- Keep the joke dry. The prose is funny because it is written straight.
- Every number in the prose traces to a file in `results/` or `data/`.
