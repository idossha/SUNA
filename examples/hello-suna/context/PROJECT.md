## Question

Does using SUNA change how a working scientist spends their week, and how they
feel about it? This is also the example project that ships with SUNA, so the
second question it answers is what a complete SUNA project looks like.

## Data

`data/happiness.csv` — one self-reported score per week, per condition, for
twelve weeks. `data/timesheet.csv` — hours per week on four manuscript chores
over twenty-four weeks, hand-kept. `data/chores.csv` — the before/after summary
behind Figure 1b. One participant. No institutional review was sought and none
would have been granted.

## Prior work

Nothing that would survive review. The control condition is the participant's
previous text editor, recalled and re-scored from memory for weeks 1–12.

## Deliverable

A manuscript, a supplement, a cover letter and an answered round of referee
reports — one of everything a paper is made of, small enough to read in a
sitting.

## Scope and non-goals

In scope: showing the whole shape of a SUNA project with real, regenerable
files. Not in scope: convincing anybody of the result. The result is a joke; the
files are not.
