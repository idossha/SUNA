# Supplementary Methods

The velocity field in the demo data cube is a rotating-disk toy model with
a seeded kinematic asymmetry, generated by
`figures/fig-velocity-map/source/plot.py` with matplotlib [@hunter2007].
The parameters below reproduce it exactly.

## Model parameters

| Parameter | Value | Unit |
| --- | --- | --- |
| Inclination | 55 | deg |
| Asymmetry amplitude | 18 | km s$^{-1}$ |
| Seed | 42 | — |
