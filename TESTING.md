# Testing SUNA

## The example project

`examples/demo-paper/` is a complete, self-contained research project used
for both human and agent testing: a four-section manuscript (math,
citations, cross-references, a table, a raw-LaTeX block), seven BibTeX
references, two figures **generated by the scripts stored beside them**
from the CSVs in `data/`, and the Nature Astronomy profile active in
`suna.json`.

Regenerate the figures at any time (from `examples/demo-paper/`):

```bash
uv run --project ../../python/suna_mpl python figures/fig-spectrum/source/plot.py
uv run --project ../../python/suna_mpl python figures/fig-velocity-map/source/plot.py
```

## Human walkthrough (~3 minutes)

1. `pnpm install && pnpm dev`
2. Welcome screen → **Open example**. The explorer shows the project;
   the intro section opens; the status bar shows *Nature Astronomy*.
3. **Manuscript**: edit `01-introduction.md`; press **⌘E** — the rendered
   view shows KaTeX math (labelled display equation), gold citation
   superscripts, blue cross-refs. ⌘E again returns to source. ⌘S saves.
4. **Canvas**: in the explorer open
   `figures/fig-spectrum/figure.svg`. The toolbar reads *180.0 × 58.0 mm*.
   Click a panel title or legend text — the selection names the semantic
   element (`ax0.title`, `ax0.legend`). Drag it; **⌘Z** undoes; **⌘S**
   saves. Scroll pans, ⌘-scroll (or pinch) zooms.
5. **Compliance**: the example figures are clean. To see diagnostics,
   open `packages/canvas/fixtures/mpl-two-panel.svg` from a project that
   contains a copy of it, or edit a figure's text to a large size — an
   *N issues* chip appears in the canvas toolbar; click it for the list
   (rule id, measured value vs the journal's stated rule).
6. **Reproducibility**: rerun a figure's `source/plot.py` (command above)
   and reopen — canvas edits saved to the SVG are currently overwritten by
   regeneration; the provenance overlay that replays them lands next.

## Agent / CI smoke test

```bash
pnpm smoke        # = node scripts/e2e/smoke.mjs
```

Launches the app with a DevTools-protocol endpoint (`SUNA_SMOKE_PORT`,
default 9321), then drives and asserts the full loop:

1. welcome renders → 2. example project opens (profile chip, tree, dev
seam) → 3. intro section in CodeMirror → 4. rendered mode has KaTeX +
citation chips + equation anchor → 5. figure mounts on canvas at 180 mm →
6. example figure has **zero** compliance issues → 7. trusted-input drag +
⌘S produces a **one-line transform diff** in the saved SVG → 8. ⌘Z + ⌘S
restores the file **byte-identical**.

Exit code 0 = pass. Failure screenshots land in `scripts/e2e/.artifacts/`.
The script restores `figure.svg` afterwards, so the working tree stays
clean. Ad-hoc driving during development: run
`SUNA_DEBUG_PORT=9310 pnpm dev`, then evaluate JS in the page (the
renderer exposes `window.__sunaDev` with `openFileTab`, `projectStore`,
`uiStore` in dev builds).

## Unit gates

```bash
pnpm typecheck && pnpm test          # all workspace packages
cd python/suna_mpl && uv run pytest  # matplotlib companion
```
